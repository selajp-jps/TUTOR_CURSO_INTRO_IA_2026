## Preguntas frecuentes

**¿El Módulo 0 es obligatorio?**
No. Es optativo y asincrónico. Sus dos actividades no cuentan para el 75% de actividades asincrónicas.

**Nunca usé ninguna de estas herramientas, ¿puedo seguir el curso igual?**
Sí. El taller está diseñado para docentes con poca o ninguna experiencia previa, y este módulo existe justamente para nivelar el punto de partida.

**Ya uso ChatGPT hace tiempo, ¿me sirve el Módulo 0?**
Puede recorrerlo rápido o saltearlo. Conviene igual mirar el Bloque 3, porque plantea la lógica que atraviesa todo el curso: primero el texto, después los demás formatos.

**¿Tengo que pagar alguna suscripción?**
No. Todo el taller trabaja sobre versiones gratuitas. Si en algún punto una versión paga ahorra mucho tiempo, se avisa con claridad qué se puede hacer gratis y dónde está el límite.

**¿Puedo cargar trabajos de mis estudiantes para probar?**
No es recomendable. Hasta no conocer bien la política de privacidad de una herramienta, conviene usar ejemplos ficticios o materiales propios, sin datos personales, notas ni trabajos con nombre y apellido.

**Una herramienta me pide la tarjeta de crédito para "verificar mi identidad", ¿es normal?**
Es una práctica cada vez más común, incluso en planes que después no cobran nada. No es automáticamente una estafa, pero conviene leer bien qué dice y buscar esa herramienta puntual en internet antes de cargar un medio de pago.

**¿Hay descuentos para docentes universitarios?**
Varias plataformas ofrecen versiones pagas sin cargo o con descuento para el ámbito académico, verificando la condición docente con el correo institucional. **Todavía no se verificó cuáles funcionan efectivamente con un correo de la UNLu**, así que por ahora es una posibilidad a explorar, no algo confirmado. Si alguien prueba una y le funciona, es un dato útil para compartir en el foro.

**¿Por qué la IA a veces inventa cosas?**
Porque arma sus respuestas combinando patrones aprendidos, no buscando una respuesta guardada. Puede sonar segura y estar equivocada, mezclar datos o inventar una cita. La revisión final siempre es del docente.

**¿Hace falta saber inglés o instalar programas?**
No. Todo lo que se usa en el taller funciona desde el navegador, en español, con una cuenta gratuita y sin instalar nada.
